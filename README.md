
# InternNova Homepage Redesign

## Project Overview
This project is a redesigned homepage for InternNova. It provides a modern, professional and user-friendly interface to help students explore internship opportunities and learn about the organization.

## Project Objective
The objective is to redesign the InternNova homepage using HTML, CSS and JavaScript while applying responsive web design principles.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Git and GitHub
- GitHub Pages

## Main Features
- Modern navigation bar
- Attractive hero section
- About InternNova section
- Internship program cards
- Internship domains
- Why Choose InternNova section
- How It Works section
- Student experience section
- Call-to-action section
- Responsive layout for desktop and mobile

## Responsive Design
The website uses CSS Flexbox, spacing, media queries and responsive styling to adjust its layout to different screen sizes.

## JavaScript Functionality
JavaScript is used to handle navigation clicks, button interactions and program card hover effects.

## Challenges Faced
One challenge was creating a responsive layout that displays properly on different screen sizes. Another challenge was organizing the project files and deploying the website through GitHub Pages.

## Solutions Implemented
CSS media queries and flexible layouts were used to improve responsiveness. GitHub Pages was used to publish the website online.

## Key Learnings
Through this project, I learned how to structure webpages with HTML, style them with CSS, add interactions using JavaScript, create a GitHub repository and deploy a website using GitHub Pages.

## Future Improvements
Future improvements may include a working internship application form, search functionality, FAQ section and more interactive features.
