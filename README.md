# InternNova Homepage Redesign

## Project Overview
This project is a redesigned homepage for InternNova. It provides a modern, attractive, responsive, and user-friendly interface that helps students explore internship programs and learning opportunities.

## Project Objective
The main objective of this project is to redesign the InternNova homepage using HTML, CSS, and JavaScript. It also demonstrates practical knowledge of responsive web design and JavaScript interactivity.

## Technologies Used
- HTML5 – Website structure and content.
- CSS3 – Styling, layouts, Flexbox, Grid, and responsive design.
- JavaScript – Interactive features and DOM manipulation.
- Git and GitHub – Project management and version control.
- GitHub Pages – Website deployment.

## Main Features
- Modern navigation bar.
- Attractive homepage hero section.
- About InternNova section.
- Internship program cards.
- Internship program search functionality.
- Learning domains section.
- Why Choose InternNova section.
- FAQ accordion with expandable questions.
- Application form with basic validation.
- Success message after form submission.
- Responsive design for different screen sizes.

## Responsive Design
The website uses CSS Flexbox, Grid, media queries, and flexible layouts to adjust its appearance on desktop, tablet, and mobile screens.

## JavaScript Functionality
JavaScript is used to implement:
- Internship program searching and filtering.
- FAQ accordion functionality.
- Application form validation.
- Dynamic success message after form submission.
- DOM manipulation and event handling.

Note: The application form is currently a frontend demo and does not store or submit data to a backend.

## Challenges Faced
During development, I faced challenges in creating a responsive layout, arranging website sections, and implementing interactive features using JavaScript. I also faced difficulties while uploading project files and deploying the website.

## Solutions Implemented
I used CSS media queries and flexible layouts to improve responsiveness. JavaScript functions and event listeners were used to implement interactive features. GitHub and GitHub Pages were used to manage and publish the project.

## Key Learnings
Through this project, I learned how to create structured webpages using HTML, style them using CSS, implement JavaScript functionality, test interactive features, manage project files on GitHub, and deploy a live website using GitHub Pages.

## Future Improvements
Future improvements may include backend integration, database connectivity, student registration and login, a real internship application system, and additional interactive features.
